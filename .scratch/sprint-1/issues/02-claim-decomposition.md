# Claim Decomposition & Extraction Engine

Type: engineering
Status: Clearance proposed — awaiting researcher
Cap: 1 day (claim segmentation engine & tests)

## Question

Build `src/prepare/claims.py` to extract atomic claims from English answers generated by RAG systems according to `docs/RUBRIC_V1.md` Section 2:
1. Decompose multi-sentence English answers into standalone, checkable factual propositions.
2. Resolve pronouns and indexicals (decontextualization).
3. Split conjunctions into independent assertions (atomicity).
4. Drop conversational hedges and discourse markers.
5. Identify `is_critical` (whether proposition directly answers the core informational inquiry).
6. Format output into `List[AtomicClaim]` following `src/prepare/schema.py`.
7. Support LLM-driven decomposition via `GeminiRotator` (with strict JSON mode and deterministic cache) with a deterministic fallback rule-based chunker for offline or testing mode.

## Findings & Evidence (agent)

1. **Engine Built (`src/prepare/claims.py`):**
   - Implemented `decompose_claims_rule_based` providing fast, deterministic coordination splitting, hedge cleaning, and `AtomicClaim` formatting.
   - Implemented `decompose_claims_llm` invoking `GeminiRotator` with few-shot claim extraction prompt enforcing the 5 core rubric criteria and outputting strict JSON.
   - Implemented unified `decompose_claims` entrypoint with automatic fallback routing.
2. **Schema Compliance:** All extracted claims produce validated `AtomicClaim` objects with `{item_id}_c{idx}` identifiers and `is_critical` flags.
3. **Unit Tests:** Built and verified `tests/test_claims.py` (3/3 passed).
