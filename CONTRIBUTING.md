# Code Standards & Engineering Guidelines (CONTRIBUTING.md)

All pipeline, analysis, evaluation, and reporting code in **NepFaith-120** must adhere to these standards. These rules ensure statistical validity, reproducibility, and defensibility under academic peer review.

---

## 1. Determinism
- **Single Random Seed**: All stochastic processes (pseudo-random number generators, sampling, permutations) must expose an explicit, configurable `seed` parameter, defaulted to a pinned project constant (`42`).
- **Pinned Dependency Versions**: All dependencies must be locked via `pyproject.toml` or `requirements.lock`. No floating version tags in production runs.
- **No Network in Analysis**: Once the dataset is ingested, the analysis pipeline (`src/analyze/`, `src/report/`) must operate completely offline. No runtime API calls to uncontrolled external models during analysis.
- **Identical Outputs**: Re-running the pipeline on identical raw inputs and config must produce byte-for-byte identical tables and numbers.

---

## 2. Traceability & Provenance
- **Output Watermarking**: Every generated table, figure, and interim dataset must record metadata:
  - Git commit hash of the run.
  - Configuration hash / parameters.
  - Timestamp and execution duration.
- **Provenance Tracking**: Every claim and item in the dataset must retain its origin: source document URL/ID, domain, retrieval condition, and whether it was natural or perturbed.

---

## 3. Loud Failure
- **No Silent Drops**: Rows, items, or claims must never be silently discarded via `.dropna()` without explicit logging and error accounting.
- **Stage Boundary Auditing**: Every stage of the pipeline must log exact row counts before and after processing:
  ```python
  logger.info(f"Stage input: {len(df_in)} items; Stage output: {len(df_out)} items")
  ```
- **Explicit NaN Handling**: Scorer and parser failures (e.g. RAGAS claim extraction returning empty/NaN, IndicTrans2 empty translations) must be recorded as explicit typed failure counts, not quietly swept under the rug.
- **No Bare Except**: Never catch generic `Exception` without re-raising or logging the full traceback.

---

## 4. Recovery Tests Before Trust
- **Simulation Validation**: Before running estimators on real experimental data, the statistical pipeline must pass recovery tests on synthetic data with known planted ground truth (GLIDE Monte Carlo suite).
- **Nominal Coverage Verification**: 95% confidence intervals must achieve ~95% coverage across 500 simulated replicates. If an estimator cannot recover a known planted effect, it cannot be trusted on real data.

---

## 5. Architecture: Notebooks Explore, Scripts Produce
- **No Paper Numbers from Notebooks**: Jupyter notebooks (`notebooks/`) are strictly scratchpads for visualization and exploratory analysis.
- **Production Scripts Produce Final Assets**: Every figure, table, and statistic reported in the paper must be generated by a version-controlled CLI script under `scripts/` or `src/report/`.

---

## 6. Model Call Hygiene
- **Pinned Model Identifier**: Every model invocation must specify an exact version string (e.g., checkpoint tag or revision hash).
- **Zero Temperature**: All evaluator models and LLM judges must run with `temperature=0.0`.
- **Deterministic Prompt Caching**: Prompts and responses must be cached using a hash of `(prompt_text, model_version, inference_params)` to prevent duplicate API spend and preserve auditability.
- **Refusal & Malformed Output Accounting**: Model refusals, parsing errors, or truncated outputs must be tallied separately and reported as part of system reliability metrics.

---

## 7. The Architectural Wall: Code Organization
```
src/
├── prepare/       # Data ingestion, query generation, perturbation engine (pre-freeze)
├── run/           # Model scoring arms, translation execution (pre-freeze)
├── analyze/       # PPI statistical estimators, GLIDE integration (FROZEN at Sprint 1 tag)
└── report/        # Paper table and figure generators (FROZEN at Sprint 1 tag)

data/
├── raw/
│   ├── corpus/    # Source Nepali passages (Wikipedia, Government, News)
│   └── labels/    # Gold human annotations (AGENT HAS NO WRITE ACCESS)
└── interim/
    └── preannotations/  # Model-generated pre-annotations
```
